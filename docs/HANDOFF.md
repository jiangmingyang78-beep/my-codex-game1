## 4. 锁定接口与约束

- 世界生成版本与存档格式版本独立。v3 奇遇 ID 由种子与区块决定。旧布局沿用各自的生成规则。
- `encounterProgress.discovered` 与 `encounterProgress.spent` 分别记录发现与消耗，地面奖励随存档保存。
- `stampSetPieceIntoWorld(worldGrid, setPiece, originX, originY, rng)` 使用格坐标。地图控制台生存覆盖配置落盘到 `public/survival-balance.json`。
